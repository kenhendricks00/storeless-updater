Screen date: 2026-07-27

Scope: downloadable Windows software, primarily United States launch use, with a basic international and multi-surface screen. Likely relevant categories include downloadable software and hosted software services (Nice Classes 9 and 42), although class numbers alone do not decide trademark conflicts.

## Recommendation

Use **BinaryFerry** as the project name. It describes the launcher metaphorically ferrying a signed application package from Microsoft's delivery service to a local versioned directory, without using OpenAI's trademarks as the project's own brand.

This is a preliminary knock-out screen, not legal clearance. No search can guarantee that a name is available, and a trademark attorney should review the final name and logo before significant commercial use.
